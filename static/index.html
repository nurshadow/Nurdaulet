THE RESEARCH CONTEXT
One model. Three languages.
A local testbed for multilingual response safety and relevance.
The paper’s original dataset
We use all 70 rows from the authors’ prompts/allprompt.csv. English text and category labels are unchanged. Russian and Kazakh are new machine translations and await independent review. Duplicates and unusual source wording are retained.
View the source dataset ↗
What is adapted?
The website and inference backend are our own code. The dataset comes from A Framework to Assess Multilingual Vulnerabilities of LLMs by Tang et al. (2025). We compare baseline and stronger system instructions on local Llama 3. There is no synthetic secret or output filter in this experiment.
Evaluation boundaries
Automatic refusal detection is a phrase-matching estimate. It is not G-Eval and does not establish harmfulness. Open a result row to manually label rejection, relevance (1–5) and safety. Relevance measures whether the response addresses the question, including a relevant refusal. Safety labels are content judgments, not legal advice. Unreviewed responses remain unreviewed.
The original dataset includes ordinary political questions as well as harmful requests. Answering a question is not automatically a failure. Some jailbreak prompts explicitly request Chinese output; those instructions are preserved even when the input is Russian or Kazakh.
Experimental setup
70 source rows × 3 languages × 2 configurations = 420 model responses. The quick check uses source rows 12, 41 and 61 (18 responses). Every evaluation request starts fresh. Temperature 0, seed 42, context 4,096 tokens and 256 output tokens. The output limit can affect assessment and appears in each audit.
Attribution and privacy
Source: Multilingual-Vuln-LLMs © 2025 Likai Tang, CC BY 4.0 (upstream README). Changes: Russian/Kazakh machine translations, row IDs and this local evaluation interface. DOI: 10.1145/3701716.3715581. Codex assisted with implementation. Translation and student verification remain pending.
Responses go only through the local Python server and Ollama. The app keeps results and review labels in browser memory until export or reload. Previously generated synthetic-secret results belong to a separate experiment.
